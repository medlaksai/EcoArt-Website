# EcoArt-Website
Développement d’un site web moderne, accessible et responsive pour EcoArt, une plateforme dédiée à la promotion et à la vente d’objets d’artisanat éco-responsables fabriqués à partir de matériaux recyclés. Projet réalisé par Nexora avec une approche Mobile-First, CSS pur, Flexbox et CSS Grid.
